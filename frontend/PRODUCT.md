# Phantom Code Reviewer (PCR)

**The Problem:** Vibecoding is easy, but debugging is hell. AI generates code quickly, but often misses deep logical, security, and performance bugs.
**The Solution:** PCR is an automated Principal QA Engineer. It runs comprehensive, multi-agent AI reviews on GitHub Pull Requests.
**Tech Stack Context:** Event-driven backend using Kafka, Spring Boot, and 4 specialized AI agents (Logic, Syntax, Performance, Security).
**Target Audience:** Developers and teams needing brutal, instant code quality checks before merging to production.
